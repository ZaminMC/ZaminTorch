## Applicability contract (from Phase 1, unchanged)

- Vanilla 1.8.8 authority = `reference/1.8.8/` (§0.7/§17). KigPaper patches
  that FIX vanilla 1.8.8 bugs are **fork divergences from the reference**:
  Torch reproduces the reference behavior (§17 "preserve observable quirks")
  and records the divergence; adopting any is an owner decision.
- Bukkit API line (both `*-API` stacks): governed by §27.9/§28.7 — deferred
  adapter decision (DEC-002), NOT per-patch Torch debt.
- Config-gated gameplay alterations (KigPaper's stated policy): one family
  decision — DEC-003 — never 60 separate rows.
- Performance patches: engineering lessons, gated on ML-007 attribution.
